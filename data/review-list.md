## Kuidas parandada

Lisa `data/overrides.json` faili `songs` alla:

```json
"loo-id-siia": {
  "_note": "miks käsitsi",
  "youtubeId": "videoId",
  "spotifyId": "trackId"
}
```

Seejärel `npm run build:data && npm run deploy`. Käsitsi kinnitatud lood
kaovad sellest nimekirjast ära, ka siis kui automaatne kindlus jäi madalaks.
